# Google Play 스토어 등록 정보

Play Console → 앱 → **스토어 등록정보(기본)** 에 아래 내용을 그대로 붙여넣으면 됩니다.
글자 수 제한: 앱 이름 30자 · 간단한 설명 80자 · 자세한 설명 4,000자.
영어·일본어·중국어 문구는 `listing_i18n.md`.

## 간단한 설명 (80자)

```
생년월일시만 입력하면 사주 여덟 글자와 오행, 일간 성격, 매일 달라지는 오늘의 운세를 풀어드려요.
```

## 자세한 설명 (4,000자)

```
🔮 내 사주팔자, 한 번 입력하면 매일 새로운 운세

「나의 사주팔자」는 생년월일과 태어난 시각을 한 번만 입력하면 사주 원국(여덟 글자)을 자동으로 세워
성격·오행·십신을 풀이하고, 매일 달라지는 오늘의 운세를 보여주는 앱입니다.
회원가입도, 로그인도 필요 없습니다.

✨ 주요 기능

• 사주 원국 자동 계산
  연주·월주·일주·시주의 천간과 지지를 절기(입춘·경칩 등) 시각 기준으로 정확히 계산합니다.
  태어난 시각을 모르면 시주 없이 여섯 글자로 풀이해 드려요.

• 일간(日干)으로 보는 나의 성격
  갑목(큰 나무)·병화(태양)·임수(바다) 등 열 가지 일간별 성격과 강점을 알려드립니다.

• 오행 분포 분석
  목·화·토·금·수 가운데 강한 기운과 부족한 기운을 그래프로 한눈에.
  부족한 오행을 보완하는 색·방향·생활 습관까지 안내합니다.

• 십신(十神) 풀이
  비견·식신·정재·정관·정인 등 내 사주에 들어 있는 십신의 의미를 쉽게 설명합니다.

• 오늘의 운세
  오늘의 일진(日辰)과 내 일간의 관계로 산출한 운세 지수(0~100), 별점,
  행운의 숫자·색·방향을 매일 새롭게 보여드립니다.

• 매일 아침 알림
  원하는 시간에 오늘의 일진과 운세를 알림으로 받아보세요.

• 이미지로 공유하기
  내 사주 원국과 오늘의 운세를 예쁜 카드로 만들어 카카오톡, 인스타그램, 문자로 공유할 수 있습니다.

• 4개 언어 지원
```
