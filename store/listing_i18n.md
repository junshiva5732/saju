## 日本語 (ja)

**アプリ名 (30)**
```
私の四柱推命 - 命式と今日の運勢
```

**簡単な説明 (80)**

```
生年月日時を入れるだけ。命式（八字）と五行、日干の性格、毎日変わる今日の運勢を鑑定。
```

**詳しい説明**
```
🔮 私の命式と、毎日新しい運勢

「私の四柱推命」は生年月日と出生時刻を一度入力するだけで命式（八字）を自動で作成し、
性格・五行・通変星を解説、毎日変わる今日の運勢をお届けするアプリです。
会員登録もログインも不要です。

✨ 主な機能

• 命式の自動計算
  年柱・月柱・日柱・時柱の天干地支を、節入り時刻に基づいて正確に計算します。
  出生時刻が不明でも時柱なしの六文字で鑑定できます。

• 日干で見る性格
  甲木（大樹）・丙火（太陽）・壬水（海）など十種類の日干ごとの性格と強みを解説。

• 五行バランス
  木・火・土・金・水のうち強い気と足りない気をグラフで一目で確認。
  補うための色・方位・生活習慣もご案内します。

• 通変星（十神）の解説
  比肩・食神・正財・正官・正印など、命式にある通変星の意味をわかりやすく。

• 今日の運勢
  今日の日柱と自分の日干の関係から運勢指数（0〜100）と星評価、ラッキーナンバー・カラー・吉方位を毎日更新。

• 朝の通知
  好きな時刻に今日の日柱と運勢をお知らせ。

• 画像で共有
  命式と今日の運勢をカード画像にして LINE や Instagram で共有できます。

• 4言語対応
  日本語 · English · 한국어 · 简体中文

🔒 プライバシー
入力した出生情報は端末内にのみ保存され、サーバーには送信されません。

---
※ 鑑定内容は娯楽・参考目的のものです。
※ このアプリには広告が含まれます。
```
